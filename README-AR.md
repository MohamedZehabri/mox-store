# متجر إلكتروني مستقل — متجر أزياء MOX — نسخة قابلة للإعداد والنشر

واجهة متجر عربية RTL بتصميم بسيط وأنيق، العملة DA، سلة مشتريات، نموذج طلب مع الولايات والبلديات (قائمة 69 ولاية مع إدخال البلدية)، ولوحة إدارة للمنتجات والطلبات.

## ما الذي يعمل الآن؟
- واجهة المتجر والبحث والتصنيفات وسلة المشتريات.
- نموذج طلب مع الاسم والهاتف والولاية والبلدية والعنوان وملاحظة.
- عند ربط Supabase: حفظ المنتجات والطلبات على قاعدة بيانات مشتركة، ويُحتسب إجمالي الطلب من أسعار المنتجات داخل قاعدة البيانات عبر Trigger، ولوحة دخول للمدير وإدارة المنتجات وحالات الطلبات.
- من دون إعداد Supabase: يعمل الموقع في وضع معاينة بمنتجات تجريبية، ولا يرسل طلبات حقيقية.

## النشر والإعداد

### 1) إنشاء قاعدة البيانات
1. أنشئ مشروعاً مجانياً على https://supabase.com/
2. افتح SQL Editor في مشروعك.
3. انسخ محتوى `schema.sql` وشغّله.

### 2) إعداد مفاتيح الاتصال
1. من Supabase افتح Project Settings ثم API.
2. انسخ Project URL و anon/public key.
3. انسخ `config.example.js` وسمّ النسخة `config.js`.
4. ضع القيم مكان `YOUR-PROJECT` و`YOUR_SUPABASE_ANON_PUBLIC_KEY`.
5. لا تضع أبداً `service_role` key في ملفات الموقع أو المتصفح.

### 3) إنشاء حساب المدير
1. من Supabase افتح Authentication ثم Users وأنشئ حساباً ببريدك وكلمة مرور قوية (أو فعّل التسجيل وأنشئه).
2. انسخ User UID للحساب.
3. في SQL Editor نفّذ، مع استبدال UUID:
   `insert into public.admins (user_id) values ('ضع-USER-UID-هنا');`
4. افتح `admin.html` وسجّل الدخول. لا يمكن فتح لوحة الإدارة إلا للحساب الموجود في جدول admins.

### 4) النشر على Netlify
1. فك ضغط الملف.
2. تأكد من وجود `config.js` بجانب `index.html`.
3. اسحب مجلد المشروع إلى صفحة Netlify Drop أو اربطه بمستودع Git.
4. بعد النشر اختبر طلباً تجريبياً، ثم احذف الطلب التجريبي.

## ملاحظات مهمة قبل استقبال زبائن حقيقيين
- يجب إدخال أسعار التوصيل الفعلية حسب الولاية/البلدية بعد الاتفاق مع شركة التوصيل. لا توجد أسعار شحن افتراضية مضمّنة حتى لا تظهر للزبون أسعار غير صحيحة.
- راجع سياسة الخصوصية وشروط البيع ومعلومات التواصل.
- أضف حماية إضافية ضد الرسائل المزعجة (مثل CAPTCHA / Edge Function أو خدمة تحقق) قبل فتح استقبال الطلبات على نطاق واسع.
- بيانات المنتجات التجريبية لا تُحفظ في قاعدة البيانات. المنتجات الحقيقية تُضاف من لوحة الإدارة بعد الربط.
- لا يوجد دفع إلكتروني في هذه النسخة؛ طريقة الدفع هي الدفع عند الاستلام. إجمالي المنتجات يعاد احتسابه داخل قاعدة البيانات، ولا يشمل التوصيل.
- الولاية تعرض قائمة 69 ولاية؛ البلدية حقل قابل للكتابة مع اقتراحات، ويجب استكمال بيانات البلديات من مصدر رسمي قبل فرض اختيار القائمة.
- لا تعتبر الموقع جاهزاً تجارياً قبل إكمال إعداد Supabase، اختبار الصلاحيات والطلبات، وتحديد شركة التوصيل والأسعار.

## بنية الملفات
- `index.html`, `style.css`, `app.js`: واجهة المتجر.
- `admin.html`, `admin.js`: لوحة الإدارة.
- `schema.sql`: الجداول وسياسات الوصول.
- `config.example.js`: قالب الإعداد.
